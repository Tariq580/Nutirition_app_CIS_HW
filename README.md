Nutrition app: 

A simple personal nutrition tracker which we can use to enter what you eat and how much (maybe taking a pic of it), and the app calculates your nutrition. It could calculate: Calories, Protein Fiber, Carbohydrates, Daily goals, Weekly goals. Some features I would like this app to have: Nutrition tracking, Diet planning for weight gain and loss, Reminders to eat based on daily and weekly goals, Recommendation of food based on daily and weekly goals. For Tech stack I would like to use Swift UI, firebase for backend.
